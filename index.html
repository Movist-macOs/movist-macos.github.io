Movist

The elegant media player for macOS. Built on QuickTime and FFmpeg, Movist delivers seamless playback with stunning high-quality captions and a refined interface that fades into the background.

Immersive Interface

Controllers appear only on hover, with a transparent title bar for uninterrupted viewing. Real-time status in the menu bar, thumbnail previews on the seek slider, and full support for macOS light and dark themes.

Smart Media Opening

Default preferences apply instantly: set track languages, video quality, filters, equalizer, and resume from last position. Tailor subtitles to English audio or preferred languages without manual tweaks.

Multi-Track Mastery

Display multiple subtitles simultaneously with custom positions and styles per language. Play dual video and audio tracks side-by-side—perfect for black box footage or complex files.

Precision Playback

High-quality customizable captions in SMI and SRT formats. Playlist support, full-screen controls, and universal binary for flawless performance across Apple Silicon and Intel Macs.

Refined Stability

Version 2.15.3 fixes playback stutters, subtitle crashes, and color issues. Enhanced A/V sync, Now Playing in menu bar, and smooth media keys on the latest macOS.

How It Works

1. Open Your Media

Drag any file or use Quick Open. Defaults apply automatically—language tracks, quality settings, and playback position restored.

2. Customize Tracks

Select multiple audio, video, or subtitle tracks. Position dual subtitles or split-screen videos with precise styling controls.

3. Play with Precision

Hover for thumbnails and controls. Adjust captions, equalizer, or filters on the fly. Full-screen mode keeps everything distraction-free.

4. Seamless Control

Use media keys, menu bar Now Playing, or keyboard shortcuts. Resume anytime with zero setup.
